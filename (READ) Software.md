# Flutter 3.35.7 Download and Installation #
Follow the Download and Installation Steps first using VSCode as said in the Documentation of Flutter:\
https://docs.flutter.dev/install/with-vs-code \
https://docs.flutter.dev/reference/flutter-cli

Remember: Refrain from using whitespaces on your directory like ```"C:\NAME_NAME\Flutter"```.

Then Proceed to

**Flutter 3.35.7 Installation and Plugin in Android Studio**
1. From Android Studio go to "Settings".
2. Go to Plugins.
3. On the left sidebar of Settings, click Plugins (just above or below “Languages & Frameworks”).
4. Search for Flutter.
5. Install Flutter Plugin.
6. Restart Android Studio.
7. From Android Studio again go to "Settings".
8. Go to Languages & Frameworks.
9. Click Flutter.
10. Browse flutter>bin on your local directory.
11. Click "Apply" then "OK"

# Dart Download and Installation #
Follow the Download and Installation Steps first using Powershell as said in the Documentation of Dart:\
https://dart.dev/get-dart \
https://dart.dev/language

**Dart Installation Plugin in Android Studio**
1. From Android Studio go to "Settings".
2. Go to Plugins.
3. On the left sidebar of Settings, click Plugins (just above or below “Languages & Frameworks”).
4. Search for Dart.
5. Install Dart Plugin.
6. Restart Android Studio.
7. From Android Studio again go to "Settings".
8. Go to Languages & Frameowkrs.
9. Click Dart
10. Browse ```C:\tools\dart-sdk``` on your local directory.
11. Click "Apply" then "OK"

**SDK Tools**
